# BEHZAD · AI Image Generator

Powered by A. R. NIROB

Static site (`index.html`) using Puter.js (`puter.ai.txt2img`). No API key in the code, no backend.
Each visitor signs in with a free Puter account and uses their own free quota (User-Pays model), so the developer pays nothing.

## Deploy (free)
1. Push `index.html`, `README.md` (and your `logo.png`) to a GitHub repository.
2. vercel.com → Add New → Project → import the repo.
3. Framework Preset: **Other** → Deploy.

## Notes
- First image generation asks the visitor to sign in to Puter.
- Free quota, models and terms are controlled by Puter and may change.
- Named after Kamal-ud-Din Behzad, master of Persian miniature painting.
